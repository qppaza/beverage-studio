# Beverage Studio

Автономный прототип конструктора рецептур безалкогольных напитков.

## Запуск локально
Откройте `index.html` двойным щелчком. Интернет не требуется.

## GitHub Pages
1. Создайте публичный репозиторий `beverage-studio`.
2. Загрузите в корень репозитория `index.html`, `style.css`, `app.js`.
3. Откройте Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main`, folder: `/ (root)`, затем Save.
6. Через несколько минут GitHub покажет адрес сайта.

Данные пользователя сохраняются в localStorage браузера.
