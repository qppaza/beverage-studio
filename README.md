# Beverage Studio v4 FINAL

Финальная сборка: адаптивный интерфейс и изолированная печать технологической рецептуры A4.

Для GitHub Pages замените в корне репозитория: `index.html`, `style.css`, `app.js`, `README.md`.

Печать запускается через вкладку «Документ» → «Печать / PDF». Печатное окно создаётся отдельно от интерфейса, поэтому элементы сайта и дублирующиеся документы в PDF не попадают.
