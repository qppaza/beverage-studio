ИЗМЕНЕНИЯ
СВ напитка и сиропа: 504 строки приложения 12, с. 228–239 книги,
от 0,4 до 50,7 %. Табличная интерполяция C (г/дм³) ↔ массовая доля (%).
Масса СВ каждого компонента = количество в кг × СВ сырья / 100.
Количество вводится на 1000 л напитка, партия масштабирует закладку.
Сироп учитывает только компоненты этапа сиропа и его объём.
Инверсия добавляется отдельно, только по сахарозе.
Подбор по цели использует ту же таблицу, измеренная плотность не нужна для СВ.
Плотность нужна для массового баланса воды, массы напитка и CO₂.
При превышении 625,34 г/дм³ (50,7 %) документ не выпускается.
Ниже 3,99 г/дм³ положительная концентрация не экстраполируется.
Нулевое содержание даёт 0 %. Неизвестные СВ отмечены как неполный итог.
На с. 230 исправлена перестановка строк: 11,1 % = 115,74 г/дм³;
11,2 % = 116,83 г/дм³. Остальные опубликованные значения перенесены буквально.
Методика отображается в программе; источник добавлен в документы.
Добавлены ограничения ширины полей на узком экране и цвета знака в тёмной теме.
Можно создавать любые собственные рецептуры; Дюшес — отдельный пример.

Исходные формулы кислотности, пищевой ценности и коэффициент инверсии 0,0526
сохранены из версии 8.0. Присланные страницы содержат таблицы концентраций,
а не полную методику этих расчётов; полная сверка с книгой не заявляется.
