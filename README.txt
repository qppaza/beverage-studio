BEVERAGE STUDIO 8.0

ОБНОВЛЕНИЕ НА GITHUB
1. Распакуйте архив.
2. В репозитории beverage-studio откройте папку, где лежит опубликованный index.html.
3. Add file → Upload files. Загрузите НОВЫЙ index.html из этого архива с заменой старого. Нажмите Commit changes.
4. Дождитесь завершения публикации GitHub Pages и обновите страницу сайта.
5. В верхней части конструктора должно быть «КОНСТРУКТОР РЕЦЕПТУР · 8.0».

Не загружайте ZIP вместо index.html. Не создавайте вложенную папку для index.html.
Старые app.js и style.css можно оставить: новая страница их не подключает.
README.txt и CHECKS.txt для работы сайта не нужны.
Если после завершения публикации видна старая версия, закройте вкладку и откройте сайт заново. Для проверки новой публикации можно открыть сайт в новой приватной вкладке. Данные браузера не очищайте: там хранятся рецептуры.

КАК СОЗДАТЬ СВОЙ НАПИТОК
1. Нажмите «＋ Новая рецептура».
2. В «Исходных данных» введите название, объём партии, плотность напитка и сиропа.
3. Откройте «Состав» → «＋ Сырьё». Выберите базовую карточку или собственное сырьё.
4. Количество сырья всегда задаётся на 1000 л. Изменение объёма партии пересчитывает навески, а не концентрации.
5. Раскройте «Свойства сырья» и заполните необходимые данные. Для литров и миллилитров обязательно задайте плотность сырья. Сахароза задаётся отдельно от СВ.
6. Проверьте «Расчёт». Для пробы используйте «Лабораторию» и её объём.
7. Заполните утверждённые нормы и органолептику в разделе «Норма рецептуры».
8. Сохраните версию. «Мои рецептуры» позволяет открыть другие напитки и предыдущие версии.
9. В «Документе» доступны печать / PDF, настоящий DOCX, XLSX и JSON.

ПОДБОР ПО ЦЕЛИ
Сначала добавьте сырьё. Затем задайте цель СВ и/или кислотности и выберите компоненты для изменения. Если неизвестны СВ остальных компонентов, автоматический подбор СВ попросит заполнить данные. Нельзя автоматически приравнивать неизвестные СВ ароматизатора к нулю.

СОХРАНЕНИЕ
Работа автоматически сохраняется в текущем браузере. Черновики и версии разных напитков не смешиваются. Резервная копия JSON переносит коллекцию между ПК и телефоном. Это перенос файлом, не облачная синхронизация. Экспорт Excel — снимок текущего расчёта, не отдельный калькулятор с формулами.
При первом запуске переносятся старые записи bs_items / bs_lab и bev_state / bev_versions, если они есть. Старые записи не удаляются. Для прежней опубликованной версии потребуется ввести плотности, которых в ней не было.

ПЕЧАТЬ
Выберите A4, масштаб 100 %, отключите браузерные колонтитулы. Документ печатается без производственных потерь. Длинные таблицы продолжаются на следующих страницах. Предпросмотр A4 на телефоне прокручивается по горизонтали.

ОБЛАСТЬ РАСЧЁТА
Потери — равномерная потеря смеси, а не выборочное испарение.
Кислотность — стехиометрическая сумма заданных кислот; pH не рассчитывается.
Пищевая ценность выводится только при заполнении всех данных сырья.
Программа не назначает нормативные пределы добавок и не проверяет разрешённость сырья по ТР ТС.
Дюшес — отдельный учебный пример BUILD 7 с кислотой 1,83 кг; он не подменяет утверждённую рецептуру №5820 с другим составом.
