Расчётная логика

СВ компонента = масса × массовая доля СВ / 100. Прирост при 100%-ной инверсии сахарозы рассчитывается только для сахара: СВ сахарозы × 0,0526. Кислотность для лимонной кислоты моногидрата: г/л ÷ 0,7005.

Справочник сырья

В этой автономной версии свойства хранятся внутри каждой рецептуры. Изменяйте СВ и категорию непосредственно в составе. Следующий этап — общий справочник с ТНПА, плотностью и технологическими параметрами.

Методика расчёта

  1. Задайте объём готового напитка и соотношение сироп : вода.
  2. Введите массу и сухие вещества сырья.
  3. Система рассчитывает вклад каждого компонента в СВ.
  4. Для сахарозы учитывается прирост при полной инверсии.
  5. Расчётные показатели сверяются с лабораторными результатами.
