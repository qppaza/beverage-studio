Исходные данные

Начните с названия напитка и параметров партии. Все рецептуры можно свободно менять.

Количество каждого компонента задаётся на 1000 л готового напитка. Объём партии используется для пересчёта закладки. СВ рассчитываются по приложению 12 книги. Плотности напитка и сиропа необязательны для СВ; нужны для массового баланса и CO₂. Для сырья в литрах укажите его плотность.

Состав напитка

Рецептура на 1000 л. Раскройте «Свойства сырья», чтобы указать СВ, ТНПА и параметры расчёта.

Воду доводят до заданного конечного объёма. Не вводите её повторно отдельной строкой, если она уже учитывается доведением. СВ сырья и содержание кислоты — разные показатели.

Подбор по цели

Расчёт количества выбранной кислоты и сахаросодержащего сырья. Остальной состав сохраняется.

Можно задать только СВ, только кислотность или обе цели. Это подбор по материальному балансу; сладость и pH он не определяет. Сначала добавьте нужное сырьё в состав.

Расчёт партии

Концентрации — в готовом напитке. Закладка с потерями показана отдельной колонкой.

Закладка сырья

Потери моделируются как равномерная потеря готовой смеси: закладка = теоретическое количество ÷ (1 − потери / 100). При испарении или выборочной потере компонентов требуется отдельный баланс.

Методика

База расчёта — 1000 л

Поля состава всегда относятся к 1000 л готового напитка. На партию V л количество умножается на V / 1000. Масса готового напитка — V × ρ, где ρ задана в кг/л. Для жидкого сырья m = Vсырья × ρсырья; граммы и миллиграммы переводятся в килограммы.

Сухие вещества по книге

Источник: «Сборник основных правил, технологических инструкций и нормативных материалов по производству безалкогольной продукции», приложение 12, страницы 228–239, при 20 °C. Используются пары из столбцов «Массовая доля сахара, г на 100 г раствора (%)» и «Количество сахара, г/дм³».

Для каждого компонента mСВ = mсырья × СВсырья / 100. Суммируются сухие вещества всех компонентов. C = ΣmСВ × 1000 / V, г/дм³. По C находится массовая доля в таблице; между соседними строками применяется линейная интерполяция. Подбор «по цели» использует обратное преобразование той же таблицы.

Для сиропа учитываются только компоненты этапа «Приготовление сиропа», до инверсии. Его объём Vсиропа = Vнапитка / (1 + соотношение воды). Диапазон таблицы: 0,4–50,7 % (3,99–625,34 г/дм³). Нулевое содержание СВ даёт 0 %. Экстраполяции нет. Превышение 50,7 % блокирует выпуск документа.

Прирост при инверсии = mсахарозы × 0,0526 × степень инверсии / 100; он добавляется к массе СВ перед повторным табличным пересчётом напитка. Сахароза задаётся отдельно. Неизвестные СВ отмечаются как неполный итог. Метод применяется к сумме СВ по принятой пользователем методике; он не заменяет измерение многокомпонентной смеси.

Примечание к переносу: на странице 230 значения для 11,1 и 11,2 % напечатаны в обратном порядке. Использованы соответственно 115,74 и 116,83 г/дм³. Остальные значения сохранены по фотографиям без сглаживания.

Кислотность

Вклад кислоты = C / K, где C — г активной кислоты на литр, K — г/л на 1 см³ 1 М NaOH / 100 см³ напитка. K = M / (100 × z), где M — молярная масса кислоты, z — число нейтрализуемых протонов. Для лимонной кислоты моногидрата K ≈ 0,70047; для безводной ≈ 0,64041; для яблочной ≈ 0,67045. Активность задаётся по соответствующей форме кислоты, а не через долю сухого остатка.

Это стехиометрический ориентир. Буферность соков и экстрактов и конечная точка титрования требуют лабораторной проверки. pH по этому расчёту не определяется.

Консерванты и CO₂

Бензойная кислота, мг/л = mбензоата, кг × 10⁶ / V × активность / 100 × 122,12 / 144,11. Для калия сорбата пересчёт в сорбиновую кислоту: 112,13 / 150,22. Нормативные пределы программа не назначает. CO₂ считается от массы удержанного газа; долю удержания задайте в свойствах. Расход газа на карбонизаторе не равен содержанию газа в напитке.

Пищевая ценность

Углеводы и энергия суммируются из данных сырья на 100 г, затем пересчитываются на 100 мл напитка. Энергия не выводится автоматически только из углеводов. Базовые карточки кислот содержат расчётные ориентиры 3 ккал / 13 кДж на грамм органических кислот, карточка сахарозы — 4 ккал / 17 кДж на грамм углеводов. Уточняйте данные сырья по спецификациям. Пока хотя бы у одного компонента данные неизвестны, полный итог не выводится. Значения для этикетки и их округление вносятся в «Норму» после проверки.

Сохранение и печать

Черновики автоматически сохраняются в этом браузере. «Сохранить версию» создаёт неизменяемый снимок; открытие версии не удаляет другие рецептуры. Экспорт JSON и резервная копия позволяют перенести работу между устройствами. Печать, Word и Excel используют текущую открытую рецептуру. Печатная рецептура даётся без потерь, производственная закладка — в расчёте и Excel.

Источники и область применения

  • ГОСТ 6687.4-86 — метод определения кислотности.
  • PubChem — лимонная кислота моногидрат: молярная масса 210,14 г/моль.

ТНПА и допустимость добавок проверяются для конкретной продукции отдельно. Карточки сырья — стартовые технологические данные, а не сертификаты соответствия. Пример «Дюшес» сохранён как учебный вариант BUILD 7 с кислотой 1,83 кг, а не как новая редакция утверждённой рецептуры №5820.
